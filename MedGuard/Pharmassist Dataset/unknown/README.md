# Unknown calibration set

Place images here only if they are **not** one of the 53 labels in `raw/`.
Include different medicine strips, empty backgrounds, hands, boxes, and blurred
or partial strips. Collect 15–20 distinct source photos per unknown medicine.

This is evaluation-only data. It calibrates the confidence/margin gate to keep
unknown false acceptance at or below 3%; it must never be used for training.
